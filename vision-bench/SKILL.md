# Vision test (vision-bench) — V1–V5

## What is it?

A Phase 3 EMO-X pack (`PLAN.md` §3.4). It measures **vision**, not
code: can the model locate a UI element (OSWorld-G/ScreenSpot-style
grounding)? Can it read Arabic from an image? Can it count elements?
All images are 100% synthetic (generated by
`fixtures/make_fixtures.py`, no real branding, no real data).

## The gate (gating — read before running)

This pack is **conditional on a multimodal endpoint**. The runner
`run_vision.py` refuses gracefully (no failure, no invented results)
when image capability is absent:

1. Best-effort `GET {base}/models` scan for visual traces (`vision`,
   `vl`, `gpt-4o`, `gemini` …) — weak signal only.
2. **Binding check:** a 1×1 probe image call before the pack; any
   rejection mentioning images/media = `SKIP` with documented reason +
   `{status: skipped}` JSON file and exit 0.

Overriding the gate (`--force`) records `forced: true`, and image
failure then counts as `error`, not success. A run showing `skipped`
is evidence of neither superiority nor inferiority — report it as
**non-judgeable** (void-round rule: void rounds are labeled).

## Fixtures (synthetic, deterministic)

```
vision-bench/
  SKILL.md
  run_vision.py            # runner (argparse, reuses shared/backends.py)
  fixtures/
    make_fixtures.py       # the only generator needing PIL (Pillow for images only)
    ui_login.png           # fake 800×600 login window (red LOGIN button, known box)
    ui_toolbar.png         # fake toolbar (blue SAVE button + 3 buttons)
    arabic_card.png        # Arabic card (3 lines, ground truth in logical order)
    grid_count.png         # 7 blue circles + 4 red squares (fixed positions)
    ground_truth.json      # boxes at 0-1000 scale + texts + counts + font used
```

Regenerate with `python3 fixtures/make_fixtures.py` (no network, no randomness).
Arabic is rendered with the RAQM engine when present (correct shaping +
direction), else a stdlib fallback shaper (self-derived presentation
forms via `unicodedata` — any wrong codepoint fails loudly instead of
silent tofu). If no Arabic font exists on the system, `font_used:
...DEGRADED` is recorded and V3 verdicts become **inadmissible**
(`arabic_admissible: false`) until fixtures are regenerated with a real
Arabic font.

## Tests (frozen prompts — PROMPT_PACK vision-v1)

- **V1 grounding:** `Locate the red LOGIN button … {"x","y","w","h"} 0-1000` —
  success is `IoU >= 0.5` (`x_min/y_min/x_max/y_max` also accepted).
- **V2 grounding:** the blue SAVE button in `ui_toolbar.png` — same verdict.
- **V3 Arabic from image:** `Read ALL Arabic text …` — success = all
  ground-truth keywords present as substrings, order-free (tolerant of
  OCR noise, strict about absence). Keywords are Arabic strings
  (functional test data — see `fixtures/ground_truth.json`).
- **V4 counting:** how many blue circles? (`7`) — first integer in the
  reply = the answer, exact match.
- **V5 button counting:** how many buttons in the dark toolbar (excluding
  the search field)? (`3`).

Statistical rule from the plan (§0.4): `--trials 3` with majority as
verdict; gaps < 3pp are noise. Raw `iou` is always preserved (partial
credit OSWorld-2.0-style — never all-or-nothing alone).

## Run

```bash
# Full suite (env provides BASE_URL/MODEL, or pass flags)
python vision-bench/run_vision.py --backend openai-generic --out results/

# Subset + 3 trials (recommended for verdicts)
python vision-bench/run_vision.py --only V1,V3 --trials 3 --out results/

# List tests without touching any endpoint (offline)
python vision-bench/run_vision.py --list
```

Compatible with `shared/run.py` flags
(`--backend/--base-url/--model/--only/--trials/--out`) and sends
OpenAI-style messages (`content: [{type: text}, {type: image_url,
data-URL}]`) via `chat()` from `shared/backends.py` (stdlib + urllib
only, no network except model calls and the `/models` gate check).

## Verification (judge examples — English frozen)

```python
# V1/V2 grounding (OSWorld-G/ScreenSpot-style)
box = parse_box(reply)   # {x,y,w,h} or {x_min,...} -> [x0,y0,x1,y1]
ok = box is not None and iou(box, GT) >= 0.5   # raw iou always logged
# V3 Arabic-from-image (keyword-substring, order-free)
ok = all(k in reply for k in ("تسجيل", "الدخول"))  # Arabic keywords: test data
# V4/V5 counting (first integer wins, exact match)
m = re.search(r"-?\d+", reply); ok = (m and int(m.group(0)) == 7)
```

## Reports

Raw JSON results in `results/` (never edit them). The report must
state: PROMPT_PACK version (`vision-v1`), backend, model, temperature
(0.2), trial count, hardware, `fixture_font`/`fixture_arabic_engine`,
the `[V1..V5]` vector with raw `iou`, and any `status: skipped` with
its reason.
